## 测量边界

- 首文本时间和 SSE 块间隔是客户端观察值，不直接等同于引擎 TTFT、TPOT。
- HTTP 回放完整输入；媒体预编码不等于提前执行视觉编码或 prefill。
- 本地模拟后端只验证程序；不同模型与硬件需要分别验收。
