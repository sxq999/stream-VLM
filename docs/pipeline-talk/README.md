## 层次与示例约定

实验套件包含多个配置组。每个托管配置组管理一次引擎服务生命周期，运行阶段可包含预热与多次正式回放；每轮回放产生多个查询请求。图中的“视频 A”与“配置组 1/2”是不同对象。

贯穿示例为视频 A：A0、A1、A2 在 1/2/3 秒到达，Q0 在 3.5 秒出现，A3 在 4 秒到达。示例显式启用 `recent, max_frames=2`，因此 Q0 使用 A1、A2。默认模板仍为 `full`。示例时间和重复次数不代表性能测量。

图示对应当前图片与文字的前缀重放路径，不宣称持续 KV 淘汰或跨查询状态复用。CPU 工作线程负责发请求，GPU batch 和 CUDA threads 属于后端执行内部。
