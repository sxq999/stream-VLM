# 历史归档

这里保存旧材料用于追溯。当前能力看[状态](../status.md)，汇报使用[八页版 PPT 与讲稿](../presentation/README.md)。

| 目录 | 内容 |
|---|---|
| `spec/` | 最初任务书与任务清单，“尚未实施”等文字属于当时规划 |
| `experiments/` | 早期小图像压测与磁盘 PD 调试说明 |
| `briefing/` | 最早的 24 页综合汇报 |
| `pipeline-design/` | 中间版 10 页管线设计汇报 |

旧材料可能含过时的能力说明与机器路径。当前操作以 `docs/guides/` 为准，原始规划不等于已完成能力。
