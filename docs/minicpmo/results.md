# 已有结果与边界

日期：2026-11-21。配置见[两卡文件](../../configs/minicpmo/two_gpu_smoke.yaml)，版本见[来源](sources.md)。

## 已验证

| 检查 | 结果 | 证据 |
|---|---|---|
| 官方音视频短回放 | 会话正常创建/结束，无协议错误；36 个原片帧，结尾另加 5 个重复帧；31 次倾听、3 次说话；9 段音频，24 kHz 单声道、6.28 秒且非静音 | [短回放 JSON](evidence/smoke-av-20261121.json) |
| 预热后重复 | 同一片段在 3 个新会话均通过；每次返回 9 段音频、6.28 秒；音频哈希不同，未宣称逐位一致 | [重复 JSON](evidence/warm-av-20261121.json) |
| 网页/实验互斥 | 网页会话阻止实验启动；实验独占拒绝新网页会话；结束后官方会话握手恢复；实际短回放入口也遵守该锁 | [互斥 JSON](evidence/web-experiment-exclusion.json) |

输入为模型自带 `omni_duplex1.mp4` 及原音轨，参考声音为 `HT_ref_audio.wav`。按真实时间提交，音频约每 200 ms 一包、画面 1 帧/秒，关闭滑动窗口，结尾补 5 秒静音。采用官方客户端，不提前发送未来内容。

硬件是两张 RTX 3090；Thinker 在逻辑 GPU 0，Talker/Code2Wav 在逻辑 GPU 1。当前最多 1 个活跃会话。完整权重清单、34 个 LFS 源哈希检查、环境 freeze、原始事件、声音与启动日志保存在实验目录；公开仓库只保留上表精简证据。

## 运行条件

- vLLM 0.32.0+cu129、Omni 固定 commit、Torch 2.13.0+cu129；语音依赖补齐后 271 个包兼容性检查通过。
- Thinker 图捕获在 24 GiB 卡的预检中显存不足，因此当前使用 `enforce_eager: true`。正式性能基线仍需核验合适的图优化/并行配置。
- 即时编译使用任务局部指定的现有 CUDA 12.6 编译器；未修改系统驱动或工具链。
- 本地 Windows 的 3 项完整性/部署测试通过；Linux 的 5 项锁/进程测试通过。这些软件测试不代替 GPU 性能测量。

## 尚不能证明

没有完成语义正确性、主观音质、长会话、打断恢复和并发隔离的全面验收。上述 3 次重复是同一片段，不是 3 个独立负载。官方客户端当前结果中部分延迟为 null，不能据此给出 TTFT/首音频延迟或实时性能结论。

尚无充分压力测试、饱和容量结论、普通双工 PD 基线或分批传输收益。接入互斥不隔离其他 GPU 任务或直接访问后端的客户端。下一步按[实验计划](plan.md)执行。
